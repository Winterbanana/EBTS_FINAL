EBTS Launcher
==============

Double-click "EBTS System Launcher.lnk" to:
- Start Apache and MySQL through XAMPP
- Open the XAMPP Control Panel
- Start the Vite frontend if it is not already running
- Open the EBTS system in your browser

The launcher uses the installed paths:
C:\xampp
C:\xampp\htdocs\EBTS

Keep Apache and MySQL running while using the system.
