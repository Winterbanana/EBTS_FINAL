SECTION A

🔐 Login & Authentication Errors

Errors that appear on the Login Page when signing in to the system.

A1
Invalid ID or Password
Login
Screen Preview
WCC Equipment System — Login
ID Number
Password
⚠ Invalid ID number or password. Please check your credentials and try again.

💬 Error Message

"Invalid ID number or password. Please check your credentials and try again."

🔍 Possible Causes

  • The ID number was typed incorrectly
  • The password is wrong (case-sensitive)
  • The account does not exist in the system

✅ Solution

  • Double-check your ID number format (e.g., 2024-07-001234)
  • Make sure CAPS LOCK is off before typing your password
  • Use the "Forgot Password" link if you cannot remember your password
  • Contact an Admin to verify your account exists
A2
Account Locked — Too Many Failed Attempts
Login
Screen Preview
WCC Equipment System — Login
ID Number
Password
🔒 Account Locked. Too many failed login attempts. Your account has been locked for 15 minutes. Please try again later.

💬 Error Message

"Account Locked. Too many failed login attempts. Your account has been locked for 15 minutes."

🔍 Possible Causes

  • You entered the wrong password 5 consecutive times
  • Someone else attempted unauthorized access to your account

✅ Solution

  • Wait 15 minutes for the lockout to expire automatically
  • After 15 minutes, try logging in again with the correct password
  • Use "Forgot Password" to reset your password if you have forgotten it
  • Report to an Admin if you suspect unauthorized access

💬 Warning Message

"Session Expiring Soon — You have been inactive for 14 minutes. You will be logged out in 60 seconds."

🔍 Possible Causes

  • No mouse movement or keyboard activity for 14 minutes
  • You left the system open without using it

✅ Solution

  • Click "Stay Logged In" to continue your session
  • The system auto-logs out after 15 minutes of inactivity for security
  • If you were logged out, simply log in again using your credentials

"Please fill in all required fields."

  • Enter your password in the second field

Borrowing Privilege Suspended
Login

WCC Equipment System — Dashboard
⚠ Borrowing Suspended. Your account has an unpaid penalty of ₱500.00. You cannot borrow equipment until this is resolved.
Equipment borrowing is disabled
₱ 500.00
Outstanding penalty balance

💬 Error Message

"Borrowing Suspended. Your account has an unpaid penalty. You cannot borrow equipment until this is resolved."

🔍 Possible Causes

  • You returned equipment late and incurred a penalty fee
  • Equipment was reported as missing and a replacement fee was charged
  • An Admin suspended your borrowing privilege

✅ Solution

  • Go to My Requests → Penalties to view the amount owed
  • Pay the penalty through the "Pay Penalty" option
  • An Admin must mark the payment as confirmed
  • Once confirmed, your borrowing privilege will be restored

B1

💬 Error Message

"This ID number is already registered in the system."

🔍 Possible Causes

  • An account with this ID number already exists
  • You may have already registered previously

Password Requirements:

  • Password is shorter than 8 characters

  • Example: Wcc@2026!

Borrowed
⚠ This equipment is currently unavailable. All units are borrowed. Please check back later.

💬 Error Message

"This equipment is currently unavailable. All units are borrowed."

🔍 Possible Causes

  • All units of the equipment are currently borrowed by other students
  • Equipment has been marked as missing
  • Equipment is being serviced or repaired

✅ Solution

  • Check the equipment list later when units may have been returned
  • Contact a Staff member or Admin to ask about expected return dates
  • Look for an alternative piece of equipment with the same function
D2

Borrow

WCC Equipment System — Borrow Equipment
⚠ You already have an active or pending borrow request. Please return or resolve your current borrowed item before borrowing again.
Current Request: LAN Cable Set — Due: Feb 17, 2026

💬 Error Message

"You already have an active or pending borrow request. Return your current item before borrowing again."

🔍 Possible Causes

  • You have an item currently borrowed that has not been returned yet
  • You have a pending borrow request awaiting Admin approval

✅ Solution

  • Go to My Requests and check your current borrowing status
  • Return the currently borrowed item to Staff or Admin
  • Wait for the pending request to be approved or rejected before submitting a new one

💬 Error Message

"Your borrowed equipment is overdue. A penalty has been applied. Return the item immediately."

🔍 Possible Causes

  • The equipment was not returned by the scheduled due date and time
  • The penalty accrues per hour past the due time

✅ Solution

  • Return the equipment to Staff or Admin immediately
  • Go to My Requests → Penalties to view the total amount owed
  • Pay the penalty via the "Pay Penalty" feature

⚠ Cannot delete this account. This user has an active borrowed item that must be returned first.

💬 Error Message

"Cannot delete this account. This user has an active borrowed item."

🔍 Possible Causes

  • The student still has an approved/active borrow request on record
  • The borrowed item has not been returned or resolved

  • Mark the equipment as returned before deleting the account
  • If the item is missing, mark it as missing and process the penalty

"Equipment ID already exists in the system. Use a unique ID for each item."

🔍 Possible Causes

  • An equipment item with the same ID already exists
  • The same equipment was added twice

✅ Solution

  • Check the Equipment List to see what IDs are already in use

SECTION F

⚡ General System Errors

Errors that may appear anywhere in the system related to data or access.

F1
Unauthorized Access — Wrong Role
System
Screen Preview
WCC Equipment System
🚫
Access Denied
You do not have permission to access this section.
This area is restricted to Administrators only.

💬 Error Message

"Access Denied. You do not have permission to access this section."

🔍 Possible Causes

  • A Student account is trying to access Admin-only features
  • A Staff account tried to access Admin-level controls
  • You navigated directly to a restricted URL

✅ Solution

  • Log out and log in with an account that has the correct role
  • Contact an Administrator if you need access to that section
  • Only Admin accounts can access: Account Management, Database, Analytics, Reports
F2
Profile Photo — File Too Large or Wrong Format
Profile
Screen Preview
WCC Equipment System — Profile Settings
👤
⚠ Photo upload failed. File must be JPG, PNG, or GIF and less than 5 MB.

💬 Error Message

"Photo upload failed. File must be JPG, PNG, or GIF and less than 5 MB."

🔍 Possible Causes

  • The selected image file exceeds 5 MB in size
  • The file format is not supported (e.g., BMP, TIFF, HEIC, PDF)

✅ Solution

  • Compress or resize your photo before uploading
  • Save the image as JPG or PNG format
  • Use a free tool (e.g., TinyPNG) to reduce file size below 5 MB
